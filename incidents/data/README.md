# Uganda district boundaries

`uganda_districts.geojson` contains the 136 Uganda district polygons used for
point-in-polygon routing and the authenticated operations map.

Source: [Uganda locale dataset](https://github.com/kakandemanwell/uganda),
which derives the district geometry from geoBoundaries. The source dataset is
licensed CC BY 4.0; retain attribution when redistributing this file.

The application keeps the manually selected district as a fallback for the
additional city/legacy location records that are not represented in this
boundary release.
